## 📝 Submitting a Quality Bug Report

To help us diagnose and resolve issues efficiently, please include:
1. **Clear Summary:** Concise description of the problem.
2. **Steps to Reproduce:** Exact steps taken to trigger the issue.
3. **Environment Details:**
   - Operating System (Windows, Linux, macOS)
   - Browser & Version (Chrome, Firefox, Edge, Safari)
   - Node.js & npm versions (if running locally)
4. **Console Logs & Screenshots:** Any relevant error stack traces or visual captures.
